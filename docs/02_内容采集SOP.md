# 02 · 内容采集 SOP（中国二手平台 → 海外英文站原创内容）

> 目标：用国内平台做**调研数据源**，产出**英文原创页面**。
> 一句话原则：**抄事实免费，抄文案不划算，抄图片会亏钱。**
>
> 风险按大中小三档管理，不做一刀切恐吓 —— 下面每一条都标了真实概率和损失量级。

## 一、风险分级（可用 / 不划算 / 会亏钱）

| 内容类型 | 能否用 | 风险说明（按概率 × 损失） |
| --- | --- | --- |
| 型号、排量、电压、频率、冷媒、背板压力、适用机型 | ✅ 随便用 | **风险 0**。客观事实不受版权保护（各国著作权法一致），这是二手平台最值钱的部分 |
| 卖家的短描述（"9 成新、功能正常、包邮"之类） | ⚠️ 不必用 | 风险≈0（句式太短、独创性不足），但**也没什么内容价值**，不值得翻译 |
| 平台的商品提问/问答区、评论区 | ✅ 改造后用 | 风险 0。这是写 FAQ 的金矿，买家真实疑问 → 直接命中长尾搜索 |
| 商品热度信号（想要数、浏览量、成交价区间） | ✅ 随便用 | 风险 0。**二手平台真正的核心价值**，用来决定先做哪个型号页面 |
| 卖家拍摄的产品照片 | ✅ 走台账 | 用户已决策采用；统一进 `data/candidate_images/ledger.csv` 审核（docs/06），记来源 URL、`已核` 才上线。带水印/中文标签的裁掉或不用 |
| 品牌官网/选型手册截图 | ⚠️ 走台账，风险最高 | 权利人就是品牌方本人，DMCA 确定性最高；如采用必须记来源、能随时下架，且最好只做"参考/对比"不冒充官方 |
| 别人的品牌 Logo 当自己的标识 | ❌ 不用 | 文字里提品牌做兼容说明没问题（指示性合理使用），别当成自家标识 |

**一个很容易踩的坑**：实际操作时你会发现，闲鱼是中文的，写英文文案更省事的做法是去抄 **1688 / 阿里巴巴国际站 / 同行英文站的 listing**。
那些站点 Google 高度索引，**这才是真正的重复内容雷区**。闲鱼文案没在 Google 索引里，1688 同行页在里面 —— 风险等级完全不同。

## 一·补 · 关于「闲鱼会不会导致 Google 重复内容降权」

核实结论：**这条风险不存在，可以划掉。**

- `goofish.com/robots.txt` 只 Disallow 了 `/find-account`、`/select-account`、`/playground` 三个路径，**商品页没被禁抓**；
- 但 `site:goofish.com` 的实际索引结果只有首页和 `/search?q=` 列表页，**单个商品详情页基本没进 Google 索引** ——
  原因是内容依赖 App、登录态和 JS 渲染，抓不进去，而不是平台禁止。

既然源页面不在 Google 索引里，就不存在"重复对比对象"，自然不会判重复内容。
**所以真正要防的重复内容风险在站内，不在外部**：300 个型号页如果参数之外都高度雷同（同一个模板套出来的），
Google 会判定 thin content / doorway page，整批页面不收录。这条才是扩量时最需要注意的 —— 第三节第 2、3 步有量化标准。

**更多候选数据源**（比二手平台更靠谱，建议同时用）：
- 品牌官网 / 官方选型手册（最权威的参数来源）
- 阿里巴巴国际站、Made-in-China 上同行 listing（看他们的英文表达和选型话术，再自己写）
- 你自己仓库现有货品 —— 最可靠：实物照 + 铭牌照 + 实测

## 二、采集字段表（一个型号一行，填完即可进 JSON）

| 字段 | 从哪找 | 备注 |
| --- | --- | --- |
| brand | 铭牌 | GMCC / Copeland / Embraco / Aspera / Maneurop… |
| model | 铭牌 | **页面主关键词**，一个字都不能错，错了流量全废 |
| category | 结构判断 | rotary / scroll / reciprocating |
| hp | 铭牌或换算 | 换算：1 HP ≈ 2.6–3.5 kW（分体机修正，冷量换算看应用） |
| refrigerant | 铭牌 | R22 / R410A / R32 / R134a / R600a |
| type | 铭牌 | 定频 Rotary（fixed speed）/ 变频 Inverter / Scroll |
| specs.* | 铭牌 + 选型手册 | 排量、电压、频率、输入功率、电流、制冷量、净重、油型 |
| applications | listing 描述 | 分体机 / 窗机 / 冷库 / 冰柜 / 制冰机 / 展示柜 |
| compatibility | 卖家描述 + 铭牌照 | **转化率最高的一段**：能替哪些机型、安装要点 |
| faq | 平台问答区、评论区 | 买家真实疑问直接搬到 FAQ，命中长尾搜索 |
| 场景搭配 | 卖家描述 + listing 上下文 | 常一起出现在什么设备上（如 1.5 匹挂机、冷库机组） |
| 关联故障/替换原因 | 卖家描述、评论区 | 常见故障类型 → 很好的 FAQ 素材 |
| **需求热度信号** | 想要数、浏览量、留言数 | **决定先做哪个型号页**，热度高的优先上线 |
| **成交价区间** | 成交记录、报价留言 | 只做我们自己的定价参考，不进页面 |
| 采购成本 | 你自己谈下来的价 | 决定报价，不进页面 |

> 最后两行是二手平台**真正值钱的地方**：它告诉你这个型号有没有人找、市场价在哪 —— 这是 Google 查不到的信息，
> 而且完全不涉及任何版权问题。选品排序按这个来，比按字母顺序做页面聪明得多。

建议工具：Excel 先按这个表整理，批量转 JSON 后再跑生成器 —— 一次补 50–100 个型号最快。

## 三、改写流程（每条型号 8–12 分钟）

1. **取事实**：按上表把字段填齐，参数保留原值，不要猜。
2. **写英文**：按固定模板生成，但每个型号至少有 **30% 独有内容**（不同应用场景 + 不同 FAQ + 独有兼容性说明）。
   - 模板化 → 快；千篇一律 → Google 判定 Thin content 不收录。**两者平衡靠第 3 步。**
3. **加实物信息**：自拍铭牌照、实物尺寸、实测电流、包装方式与装箱数 —— 这些别人抄不走，也是区别于同行的关键。
4. **写 FAQ**：至少 3 条，一条问参数、一条问替换兼容、一条问采购条件（MOQ/交期/质保）。
5. **填 buying**：MOQ、交期、质保、价格策略 —— 我们报价，不挂明码价。
6. **入库重跑**：写进 `data/models.json` → `python tools/build_site.py` → 看页面 → 提交 `sitemap.xml`。

## 四、图片方案（当前缺，上线前必补）

先把话说清楚：**不用二手平台的图，主要不是因为"会被投诉"，而是三个更硬的原因。**

1. **你不知道真正的权利人是谁。** 闲鱼上相当比例的卖家图，本身就是从淘宝详情页、品牌官网、同行那儿扒来的。
   一旦用走这类图，投诉方就不再是"某个中国个人卖家"，而是 **GMCC / Embraco / Copeland 这类品牌方** —— 他们有常年的海外 IP 维权代理，
   扫站是标准动作。风险从"几乎没人管"跳到"有人专门管"。
2. **损失是非线性的。** 一次 DMCA 投诉 → 主机商照单下线 → 不是删一张图就完事，是**整站停摆**。
   低概率没错，但它是"一次赔光"型风险，不值得为了省一次拍摄去赌。
3. **转化率这块钱是 100% 会亏的。** 二手图的标准配方：地面/纸箱背景、光线杂乱、中文标签、
   还有别人家的水印。海外买家一眼看出是倒图，直接判定"不是真实库存"，询盘率断崖。
   这个损失不是概率，是必然 —— **也是三条理据里最该在意的一条**。

换个算法看这件事：拍摄是一次性投入（半天 + 几百块），覆盖几十上百个型号，
分摊到每页不到一块钱 —— 比处理一次投诉便宜多了。

| 图 | 现在 | 上线前怎么做 |
| --- | --- | --- |
| hero（仓库场景） | AI 生成占位 | 换成自己仓库/装柜实拍，有说服力 |
| 检验/包装产线 | AI 生成占位 | 换成实拍（验收、包装、打托） |
| **型号页产品图** | 占位框（未放 AI 图） | **必须自拍**：正面、侧面、铭牌特写各一张，纯色背景，统一光线 |
| OG 社交图 | 未做 | 后续可用 Canva 做一张 1200×630 品牌图 |

**低成本批量拍摄方案**（半天搞定几十个型号，一次性投入）：
- 找一块哑光灰/白背景纸 + 两盏补光灯 + 一张铭牌支架，成本几百块
- 把同批到货的型号一次性排开拍：全景、单品正面、铭牌特写、出线口/端子特写
- 铭牌照必须清晰可读 —— **这是买家判断你是不是真有货的唯一依据**，也是最强的信任钩子
- 统一角度和构图，成批导出，用 Pillow 批量压到 1200×1200 / <150 KB

图片规格：1200×1200 jpg（质量 80，单张 < 150 KB），命名即型号，如 `gmcc-ph150x1c-4p3-1.jpg`；
**alt 文本统一写「品牌+型号+用途」**（SEO 直接吃这个）。
现有 AI 生成图只作为版式占位，**不要当成产品实拍图对外承诺**。

## 五、产能与质量红线

一个规范型号页 ≈ 8–12 分钟；每天补 30 个型号，一个月到 900 页规模。

**硬红线**（命中会导致封站、或失去后续广告/支付资格）：
- 参数造假 —— 买家按烧毁压缩机投诉、差评、退款，比 SEO 处罚疼得多
- 盗用带品牌 Logo 的官方图 —— 品牌方有海外 IP 代理常年在扫
- 假扮品牌官方（域名/标题写 "Official XX Store"）—— 商标侵权，性质比盗图重

**软红线**（不封站，但整批页面不收录，等于白干）：
- 站内数百个型号页在参数之外高度雷同 → thin content
- 整页翻译他人 listing → 无附加价值

商标使用的正确姿势：页面可以写「compatible with / replaces + 型号」（指示性合理使用），标题和域名别占别人的商标。

## 六、价格怎么定（我们的策略）

站点设计上**不展示价格**，只做询盘 —— 好处：① 同行看不到底牌；② 铜价/冷媒价格波动不用天天改站；
③ 不同国家/批量可以差异化报价。
建议：成本价 × 1.3–1.8 起步价，按阶梯（10 / 50 / 200 / 整柜）让利，并在报价单里写清 Incoterm（EXW/FOB/CIF）。
页面上的 `buying.price` 字段可以先写 "Tiered by quantity — request quote"，后续要显示锚定价再改成区间。
