# 06 · 图文采集台账与二手平台来源通道

> 用户已决策：**国内二手平台（闲鱼 / 转转 / 闲转等）的图文作为本站内容来源之一**。
> 本文件是该来源的**操作通道**：所有采集内容先进台账、经你审核、**绝不自动上线**。
> （上一轮论证的 DMCA / 重复内容风险已由用户知悉并自行承担，此处只保留操作纪律。）

---

## 一、为什么要有台账（而不是随手贴）

- 二手图来源杂（个人卖家 / 商家 / 搬运号），不记来源就分不清"这张图我能不能用"。
- 上线前必须能回溯到**型号 + 来源 URL + 审核状态**，出问题能立刻定位、下架。
- 文章后面要批量用二手平台图文（见第四节），台账是批量生产的内容中台。

## 二、采集步骤（每天可做）

1. 在闲鱼 / 转转搜目标型号，截图**商品主图 + 铭牌特写**（铭牌照最关键，买家靠它认货）。
2. **过两道硬门槛**（2026-10-15 用户定，不过则弃用）：
   - **无水印**：带水印的图先 `python tools/dewatermark.py in.jpg out.jpg` 去掉；**铭牌区先 `--protect` 框住防误伤；彩色水印只能 `--mask` 手涂**；去不干净的（大面积贴片水印 / 大 Logo）直接换图，别硬上。跑完必须回看成品。
   - **无人物**：出现人脸 / 人物 / 手举产品 / 卖家自拍 / 背景有人 —— **一律不用**。
3. 图片按 `<slug>-1.jpg` 命名（如 `gmcc-ph150x1c-4p3-1.jpg`），丢进 `data/candidate_images/`。
   - 系列页可用 `<slug>.jpg`，如 `gmcc-ph-series.jpg`。
   - 一个型号多张就 `-1 / -2 / -3`。
4. 运行登记脚本：
   ```bash
   python tools/collect_ledger.py
   ```
   脚本自动识别型号、把新图写进 `ledger.csv`（状态=待审），并打印待处理清单。
5. 打开 `ledger.csv`，把确认可用的行 `review_status` 改成 **`已核`**，并补 `source_url`、`caption_cn`（中文图注，上线时译成英文 alt）。
6. 推进图片到站点：
   ```bash
   python tools/collect_ledger.py --promote
   ```
   `已核` 且图片存在的行，自动复制到 `site/assets/img/<slug>-1.jpg`，生成器会优先用它，占位框失效。
7. 重建整站：`python tools/build_site.py`

> **红线**：只有 `已核` 会被推进 `site/`；`待采集 / 待审` 永远只停在 `data/candidate_images/`，不会上线。

## 三、台账字段（ledger.csv）

| 字段 | 说明 |
| --- | --- |
| slug | 型号页 slug（与 models.json 对应） |
| brand / model | 品牌 / 型号（自动带出） |
| source_platform | 来源平台（闲鱼 / 转转 / 闲转 …） |
| source_url | 来源商品链接（**必填**，审核与溯源用） |
| image_file | 候选图文件名 |
| caption_cn | 中文图注，上线时转英文 alt |
| collected_at | 采集日期 |
| review_status | `待采集` → `待审` → `已核` →（可选）`下线` |
| risk_note | 风险备注（如"水印未去""含人像""疑似搬自品牌官网""已去水印"） |
| target | 上线落到的页面 |

**审核清单（4 条全过才可把状态改成 `已核`）**：
① 无水印（或已用 `tools/dewatermark.py` 去除干净）；② 无人物；③ 铭牌 / 型号可辨认；④ `source_url` 可回溯。

## 四、文章内容管线（后续批量做）

后续一部分**文章**直接把国内二手平台的图文搬到海外站。做法：

- 一篇图文 = 一个二手 listing 的"成色 / 年份 / 运行状态 / 价格区间"整理成英文短文 + 配图。
- 文案：**不要逐句翻译卖家原话**，提炼成自己的信息点（避免与被索引的中文页重复，也避免卖家句式雷同）。
- 图片：走本台账审核；铭牌照、实拍图优先。**带水印的先 `tools/dewatermark.py` 去水印，含人像的一律不用**（硬规则，见第二节）。
- 来源标注：文章里可写 "As seen on the local second-hand market" 一类的客观表述，不冒充官方。
- 每篇同样登记到台账（把 `target` 写成文章 slug），审核后才上线。
