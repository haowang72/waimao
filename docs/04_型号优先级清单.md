# 04 · 型号优先级清单（按全球替换市场需求热度排序）

> 用途：决定**先做哪些型号页**。做完一批补一批，不用一口气铺完。
> 排序依据：全球出货/保有量 × 替换更换频率 × 目标市场（中东、非洲、拉美、南亚、东南亚）匹配度。
> **这不是精确数据 —— 是行业常识判断。** 上线前用 Google Keyword Planner、阿里国际站 RFQ 量、闲鱼"想要数"交叉核一次（方法见文末）。

## 怎么读这张表

- **确认度 A** = 系列和主流型号编号我有把握，照着填参数即可
- **确认度 B** = 系列确定，具体后缀/编号需要拿实货铭牌核对
- **确认度 C** = 只确定品牌和大致系列，具体型号要你自己从库存和平台listing里捞
- **建议页数** = 该系列覆盖的输出规模（含系列主页 + 各容量型号页）

## 建议执行顺序

| 阶段 | 做什么 | 目标 |
| --- | --- | --- |
| 第一批 | GMCC PH 系列（12–15 页）+ Copeland ZR 系列（8–10 页） | 约 25 页，覆盖最大的两块流量，上线验证收录速度 |
| 第二批 | Embraco / Aspera（16–20 页）+ Danfoss MT/MTZ（8–10 页） | 补上冷链端，型号长尾开始起量 |
| 第三批 | Highly、Donper、Tecumseh、Secop BD（25 页左右） | 铺到 100 页以上，长尾流量开始稳定带来询盘 |
| 第四批 | 按实际询盘结果反推 —— 客户问得多但还没做的型号优先 | 数据驱动补页，不再拍脑袋 |

**第一批别做太多。** 25 页上线 → 看 30 天 GSC 收录率和询盘来源 → 验证模式的才是有效页面，再批量扩。

## 怎么交叉验证「需求热度」（别只看我这个排序）

1. **Google Keyword Planner**：查 `[model] compressor`、`[model] replacement`，看月搜索量 → 最硬的指标
2. **阿里国际站**：搜同型号，看多少供应商在卖、RFQ（采购需求）数量 → 反映真实采购活跃度
3. **闲鱼 / 58**：搜型号，记"想要数"和最近发布时间密度 → 国内流通热度，**且完全无版权风险**（这是二手平台最有价值的用法）
4. **Google Trends**：横向比 `GMCC compressor` vs `Copeland compressor` vs `Embraco compressor`，看区域热度分布 → 决定先攻哪个市场

## 参数核对注意

- **串行后缀最容易错**（`-4P3`、`-PFJ-522`、`-TFD-522` 这些），同型号不同后缀可能电压/相位不同 → 一定要拿铭牌照核
- **同系列不同容量**：排量、功率、电流一定要逐个核，不能按 HP 线性推算，效率差异很大
- 所有新页先按 `data/pipeline.csv` 排队，参数齐了再转 JSON 入库，别直接写 JSON（仓库一致性会变差）
