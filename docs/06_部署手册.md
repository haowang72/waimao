# 06 · Baizly 上线部署手册（Cloudflare Pages + baizly.cn）

> 站点类型：纯静态 HTML（由 `tools/build_site.py` 生成到 `site/` 目录）。
> 托管方案：**Cloudflare Pages（免费）**，自带全球 CDN + 免费 SSL。
> 主域：**baizly.cn**（已购）；www.baizly.cn 一并绑定。
> 备选：baizly.com 赎回释放后 301 切过去（见 docs/05 阶段2）。

---

## 前置条件（必须先做）

1. **.cn 实名认证**：在注册商后台（阿里云万网 / 腾讯云 DNSPod）完成 CNNIC 实名（个人身份证或企业执照）。
   未实名 → 注册商不允许改 NS、不解析。这是 .cn 的硬要求。
2. **本地构建最新站**：改完 `data/models.json` 后跑 `python tools/build_site.py`，确保 `site/` 是最新成品。
3. **已知缺口（上线前）**：联系表单无后端（见文末"已知缺口"）。Telegram 已于 2026-11-04 整站取消，不再回填。

---

## 第一步 · 把 baizly.cn 接入 Cloudflare

1. 打开 https://dash.cloudflare.com → 注册/登录（Free 计划足够）。
2. **Add a Site** → 输入 `baizly.cn` → 选 **Free** 计划。
3. Cloudflare 扫出当前 DNS 记录后，会给你 **两个 NS 服务器**（形如 `xxx.ns.cloudflare.com` / `yyy.ns.cloudflare.com`）。
4. 去你的 .cn 注册商后台，把 baizly.cn 的 **DNS 服务器（Nameserver）改成这两个**，保存。
5. 回 Cloudflare 点 "Check nameservers" 等生效（通常几分钟~24h）。

> 注意：改 NS 之前确保 .cn 已完成实名，否则注册商可能拒绝。

---

## 第二步 · 部署站点文件

### 方式 A：控制台直接上传（最简单，无需 git/命令行）
1. Cloudflare 控制台 → 左侧 **Workers & Pages** → **Create** → 选 **Pages** → **Upload assets**。
2. 项目名填 `baizly`。
3. 把本地 `site/` 文件夹里的**全部内容**拖进上传框（根目录必须含 `index.html`；含 `categories/`、`models/`、`knowledge/`、`assets/`、`sitemap.xml`、`robots.txt`）。
4. 点 **Deploy**。会得到 `baizly.pages.dev` 临时域名，先自测。

### 方式 B：命令行（改站后重传，免每次拖拽）
```bash
# 首次安装 wrangler（只需一次）
npm install -g wrangler

# 每次改完 models.json 并重跑 build 后，一条命令重传
npx wrangler pages deploy site --project-name baizly
```
> 首次会让你登录 Cloudflare 账号授权，按提示走完即可。

---

## 第三步 · 绑定自定义域名 + SSL

1. Pages 项目 → **Custom domains** → **Add a custom domain**。
2. 添加 `baizly.cn`，再添加 `www.baizly.cn`。
3. Cloudflare 自动：
   - 签发**免费 SSL 证书**（几天内自动续）；
   - 加 CNAME 记录指向 Pages。
4. （可选）在 DNS 里给 `www.baizly.cn` 设 **CNAME 到 baizly.cn** 或开启 **Page Rule / Redirect Rules** 把 `www` 跳到根域（避免两个版本分散权重）。
5. 等 DNS 全球生效（NS 改后通常几分钟~24h）。

> SSL/TLS 模式建议设 **Full (strict)**（Pages 默认已配，勿改回 Flexible 以免循环重定向）。

---

## 第四步 · 验证上线

1. 浏览器开 `https://baizly.cn` → 看 HTTPS 绿锁、页面正常、图片/样式加载。
2. 开 `https://baizly.cn/sitemap.xml` → 确认能访问、内部链接都是 `https://baizly.cn/...`。
3. 开 `https://baizly.cn/robots.txt` → 确认指向正确的 sitemap。
4. 各联系方式点击测试：WhatsApp(`wa.me/8619176957936`)、电话(`tel:+8613401119022`)、邮件(`haow@wqsxb.com`)、微信(`13401119022`)。
5. Google Search Console 提交 sitemap（上线后做，见 docs/05 阶段4）。

---

## 第五步 · 上线后（收尾）

- **Google Search Console**：添加 `baizly.cn` 属性 → 验证（HTML 文件或 DNS TXT）→ 提交 `sitemap.xml`。
- **Bing Webmaster**：同理提交 sitemap。
- **baizly.com backorder**：在 GoDaddy / Namecheap / SnapNames 免费挂单，等赎回期释放抢注；抢到后 301 切主域。
- **监控**：Cloudflare 自带 Analytics 看访问量；联系表单/WhatsApp 询盘量做转化记录。

## 已知缺口（上线前必须处理）

1. **联系表单无后端**：当前 `/api/inquiry` 是占位。无后端时需确认它回落到 `mailto:haow@wqsxb.com`，或接 Cloudflare Forms / 企业微信 webhook（docs/05 阶段4 有列）。
2. **Telegram 已取消**：2026-11-04 用户决定不注册 TG，全站 Telegram 入口（导航/页脚/联系页/QR 码）已删除，`data/models.json` 的 `telegram` 字段已移除，部署手册、生成器同步清理。
3. **企业邮箱收件**：`haow@wqsxb.com` 是真实企业邮，需确保能正常收海外邮件（SPF/DKIM 建议配，否则易进垃圾箱）。

---

## 回滚 / 改站流程

- 任何内容修改都只动 `data/models.json` + 跑 `build_site.py` 重建 `site/`。
- 重新上传：方式 A 重新 Upload，或方式 B 重跑 `wrangler pages deploy`。
- 历史部署在 Pages 控制台保留，可一键 **Rollback** 到任一旧版本。
