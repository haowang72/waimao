## 日常操作（只有两步）

1. 编辑 `data/models.json`（新增一个型号对象，或在现有型号里改参数、改文案）。
2. 跑生成器重建整站：

```bash
cd /c/Users/Admin/Desktop/海外压缩机站
python tools/build_site.py
```

脚本会同时更新：`site/` 全部页面、`sitemap.xml`、`robots.txt`、`docs/01_关键词覆盖表.md`。
新增 100 个型号 = 新增 100 个页面，不用写一行 HTML。

## 先做哪些型号？（重要）

不要按顺序硬铺，**先做需求热度高的**。看两份东西：

- `docs/04_型号优先级清单.md` —— 按全球替换市场需求热度排序的品牌 + 系列清单（含"其他"候选池）
- `data/pipeline.csv` —— 80 条排队表，字段已对齐 `models.json`，含优先级 / 热度评分 / 型号确认度

随时看进度：

```bash
python tools/pipeline_report.py
```

补完一条就把该行 `params_status` 从 `pending` 改成 `done`。**建议第一批只做 GMCC PH 系列 + Copeland ZR 系列约 25 页，
上线验证收录和询盘后再批量扩。**

## 新增一个型号：JSON 字段模板

```jsonc
{
  "slug": "gmcc-ph190x1c-4p3",     // URL 用，小写 + 连字符，必须唯一
  "kind": "model",                 // model（单型号）或 series（系列聚合页）
  "brand": "GMCC",
  "model": "PH190X1C-4P3",         // 页面主关键词就是这个
  "category": "rotary",            // rotary / scroll / reciprocating
  "popular": true,                 // 是否出现在首页「Popular models」
  "hp": "1.5 HP",
  "refrigerant": "R410A",
  "type": "Rotary, fixed speed",
  "specs": { "参数名": "值", "...": "..." },   // 直接生成规格表
  "intro": "150–250 字英文原创概述",
  "highlights": ["卖点1", "卖点2", "卖点3"],
  "applications": ["应用场景1", "应用场景2"],
  "compatibility": "替换/兼容性说明（最有转化价值的一段）",
  "faq": [{"q": "问句", "a": "答案"}],
  "buying": {"moq": "10 pcs", "warranty": "12 months", "lead": "3–7 days", "price": "Tiered — request quote"}
}
```

`members` 字段仅在 `kind: "series"` 时使用，列出该系列包含的型号。

## 设计说明

- **浅色专业 B2B 风**（深 navy 主色 + 琥珀强调色），符合海外工业品采购站审美，也适配浅色工作台。
- 遵循你固化的 premium 设计系统规范：CSS 变量统一管理 token、4px 间距节奏、完整 hover/focus/active 微交互、
  `cubic-bezier(.16,1,.3,1)` 缓动、内联 SVG 图标（无 emoji、无图标库）、720/1000px 两档响应式断点。
- 全站无外部依赖（不加载 Google Fonts / CDN），海外访问速度与稳定性优先，部署到任何主机都能独立运行。
