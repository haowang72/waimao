# 05 · 图库与配图规范

> 目标：**给每个型号配上产品图**，来源可以是自拍 / 供应商素材 / 国内二手平台截图，统一走台账审核。
> 配套文件：`data/image_plan.csv`（80 条型号的配图计划）、`site/assets/img/products/`（图库目录）、`data/candidate_images/ledger.csv`（图文采集台账，见 docs/06）
> 配套脚本：`tools/build_placeholders.py`（占位卡）、`tools/collect_ledger.py`（登记 + 审核推进）

## 一、三条合法图源（按推荐顺序）

| # | 图源 | 成本 | 说明 |
| --- | --- | --- | --- |
| 1 | **自己拍** | 半天 + 几百块 | 唯一 100% 安全且有说服力的方案。同批到货排开拍，摊到每页不到一块钱 |
| 2 | **向上游供应商/工厂要素材包** | 几乎为零 | **最省力的一条**：他们巴不得你帮卖货，通常有现成高清图。下面有邮件模板 |
| 3 | 品牌官方资料（产品手册、选型手册） | 低 | 经销/引用用途通常被允许，但**先把许可确认清楚再用**，别默认可用 |

**二手平台卖家图（用户已决策采用）**：闲鱼 / 转转的图现在可以作为来源，但**统一走 docs/06 台账审核通道** ——
每张都要在 `ledger.csv` 里记 `source_url` 并能回溯，状态到 `已核` 才推进上线。
**两条硬规则（用户 2026-10-15 明确，违反直接不上线）**：
**① 带水印的图必须先去水印（`tools/dewatermark.py`）再用，去不干净就换图；② 图里出现人像的一律不用。**
注意：闲鱼图本身常盗自淘宝详情页或品牌官网，权利人可能是 Secop / Embraco / Copeland 这类有常驻海外 IP 代理的品牌方，
所以带水印 / 中文标签的图要么去水印、要么裁掉、要么不用，且任何一张被投诉要能立刻定位下架（台账就是为此存在的）。

> 顺带一个更值钱的发现：Secop、Embraco 官网都有公开的 **Cross Reference 替换对照表**（用 A 型号替换 B 型号）。
> 这类对照属于**事实信息，可以自由整理使用**，而且它是极高价值的 SEO 内容 —— 买家搜"用什么替换 XXXX"时直接命中。
> 这条比图片更值得先做。

## 二、向供应商索取素材的邮件模板（中英对照）

```
Subject: Product photos request for [MODEL LIST] — wholesale listing

Hi [Name],

We are preparing our export catalogue for [market: Middle East / Africa / LatAm]
and are listing the following models:

- GMCC PH150X1C-4P3
- Copeland ZR34K3-PFJ-522
- ...

Could you send high-resolution product photos for these, along with the latest
spec sheets? We are also interested in your cross-reference / replacement table
if you have one available.

We handle all marketing locally, so any brand-approved material you can share
would be used as-is.

Thanks,
[Your name] — [Company]
```

中文场景可以直接说："我们在做出口的选型目录，需要这几个型号的高清实物图和最新参数表，你们愿意给的话我们会优先推这批货。" —— 供应商基本都会给。

## 三、图库目录与命名

```
site/assets/img/products/
├─ gmcc-ph150x1c-4p3-1.jpg        正面
├─ gmcc-ph150x1c-4p3-2.jpg        侧面/端子侧
├─ gmcc-ph150x1c-4p3-3.jpg        铭牌特写
└─ gmcc-ph150x1c-4p3-placeholder.jpg   占位卡（自动生成，被实拍覆盖后自动失效）
```

**命名规则死 three 条，别破例**：
1. 文件名 = `<slug>-<序号>.jpg`，slug 必须和 `models.json` 里的 `slug` 完全一致
2. 全小写、连字符、无空格、无中文
3. **铭牌照必拍** —— 买家判断你是不是真有货，唯一依据就是这张

## 四、图片规格

| 项 | 标准 |
| --- | --- |
| 尺寸 | 1200×1200（方形产品图）或 1200×900（场景图） |
| 格式 / 质量 | JPG，质量 80–86，单张 < 150 KB |
| 背景 | 哑光灰/白，避免反光 |
| 构图 | 三个角度统一：正面正视、45° 侧面、铭牌垂直俯拍 |
| alt 文案 | `<品牌> <型号> <类型>, <HP> <冷媒> — wholesale supply`（脚本已在 `image_plan.csv` 里预生成） |

批量压缩（放在 tools/ 下备用）：

```python
from PIL import Image
im = Image.open('raw.jpg').convert('RGB')
im.resize((1200, 1200)).save('out.jpg', quality=82, optimize=True)
```

## 五、自动化（已经跑通，直接用）

```bash
python tools/build_placeholders.py          # 生成占位卡 + 刷新 data/image_plan.csv
python tools/build_placeholders.py --check  # 看哪些型号还缺实物图
python tools/collect_ledger.py              # 登记 data/candidate_images/ 里的新图到台账
python tools/collect_ledger.py --promote    # 把审核=已核的图推进 site/assets/img/<slug>-1.jpg
python tools/dewatermark.py in.jpg out.jpg  # 去水印（带水印的图必须先跑这个 —— 见第六节红线）
python tools/build_site.py                  # 重建整站（图片自动挂接）
```

**去水印工具（`tools/dewatermark.py`）**：默认自动模式，识别"低饱和度的异常亮/暗细线"型文字 / 网址水印，再 inpaint 修补：

```bash
python tools/dewatermark.py in.jpg out.jpg                          # 自动（亮暗都算）
python tools/dewatermark.py in.jpg out.jpg --mode bright --thresh 22 --strength 3   # 水印偏亮，调阈值
python tools/dewatermark.py in.jpg out.jpg --mask mask.png          # 手动蒙版（白=去除），最可靠
python tools/dewatermark.py in.jpg out.jpg --protect 285 300 545 485 # 保护铭牌/标签区（可重复），防误伤
python tools/dewatermark.py in.jpg out.jpg --crop 60 60 60 60       # 只裁掉四周水印带（上 下 左 右）
```

**实测得到的三个坑（务必注意）**：
1. **自动模式会误伤铭牌 / 标签**（铭牌高对比、细字，容易被当成水印抹掉）—— 跑之前先用 `--protect x0 y0 x1 y1` 把铭牌框起来。
2. **彩色水印（蓝色椭圆 Logo、红章、彩色贴图）自动模式去不掉**（只认中性灰）—— 这种必须用 `--mask` 手动蒙版。
3. **每次跑完必须回看成品**：优先找干净图源；实在要修，用 `--mask` + `--protect`，并逐张肉眼验收。**铭牌照一旦被抹花 = 废图**，宁可不换图也别上坏图。

**关键设计**：实拍图按 `<slug>-1.jpg` 丢进目录，**不用改任何代码**，重跑生成器页面就自动换真图，占位卡自动失效。
所以拍摄回来不用一个一个改 HTML —— 批量扔文件夹，跑一次脚本，搞定。

## 六、红线（别碰）

- **带水印的图必须先去水印再用**（否则一律不上线）—— 用 `tools/dewatermark.py`（见第五节）。去不干净的（大面积不透明贴片 / 大 Logo）直接换图，别硬上
- **网络图里出现人像的一律不用** —— 人脸、人物、手举产品、卖家自拍、背景有人，全部排除。二手平台图尤其要注意（常带卖家本人或店面人物入镜）
- 不去水印就上线 = 等于替水印方免费打广告 + 显得不专业，询盘率断崖；这条没有例外
- 不放 带他人 Logo 的宣传物料 当自己的产品图 —— 角落品牌 Logo 也算，要么抹掉（白底图可直接涂白），要么裁掉
- 不用 AI 生成的"看起来像实拍"的图充当产品照 —— 这是在对外承诺我们没有的东西，性质比盗图更糟（欺诈）
- 占位卡是**图纸风格**的，一眼看得出不是照片，这是刻意的：宁可明确写"photo pending"，也不能骗点击
