# 03 · 上线部署清单（英文站 v1）

## 一、域名

| 建议 | 说明 |

| **避开** | 不要用任何他人的品牌商标（Copeland / Embraco / GMCC / Danfoss 等）做域名主体 |

## 二、主机（关键：不要放中国大陆境内服务器）

- **原因**：大陆服务器面向境外访客需要 ICP 备案，且跨洋访问慢，Google 抓取体验差。
- **推荐**：
  - 入门：Cloudflare Pages / Netlify（静态站免费托管，自带 HTTPS + 全球 CDN，最快上线）
  - 可控：腾讯云「轻量应用服务器 中国香港」/ 新加坡（与你现有腾讯云账号一致，SSH 自己管）
  - 备选：Hostinger / Vultr / Hetzner（欧美节点，适合目标市场在欧美的阶段）
- Nginx 配置要点：开启 gzip/brotli、`Cache-Control` 给 `assets/` 设 30 天、404 页指向 `/404.html`。

## 三、SSL 与 CDN

1. Cloudflare 免费套餐：DNS 托管 + 代理开启 → 自动 HTTPS + 全球加速 + 基础 WAF。
2. HSTS 建议在稳定运行两周后再开。
3. 图片走 CDN 缓存；后续图片量大可再挂对象存储（COS 国际站 / R2）。

## 六、询盘链路（表单 → 企业微信推送）

站点表单已改成 `form.inquiry-form`，提交后 POST 到 `site` 配置里的 `inquiry_endpoint`（默认 `/api/inquiry`），
由中间层转发到**企业微信群机器人 Webhook**，团队在企微里直接收到询盘。未配置 endpoint 时自动回退到邮件。

**推荐部署（Cloudflare Worker 中转，隐藏 Webhook Key + 解决浏览器跨域）：**

```js
// worker.js  —— 绑定到你的域名 /api/inquiry
export default {
  async fetch(request, env) {
    if (request.method !== 'POST') return new Response('Method Not Allowed', {status:405});
    const data = await request.json().catch(() => ({}));
    const lines = Object.entries(data).map(([k,v]) => `${k}: ${v}`).join('\n');
    const body = { msgtype: 'text', text: { content: `【海外站新询盘】\n${lines}` } };
    const r = await fetch(`https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=${env.WECOM_KEY}`, {
      method: 'POST', headers: {'Content-Type':'application/json'}, body: JSON.stringify(body)
    });
    return new Response(JSON.stringify({ok: r.ok}), {headers:{'Content-Type':'application/json'}});
  }
}
```

- 把企业微信群机器人 Webhook 的 `key` 存为 Worker 环境变量 `WECOM_KEY`（**不要写进前端代码**）。
- 群机器人在企微 → 某个群 → 群机器人 → 添加 → 复制 Webhook URL 里的 `key`。
- 静态站 `data/models.json` 里 `inquiry_endpoint` 填你的 Worker 地址（如 `https://api.yourdomain.com/api/inquiry`）。
- 联系方式同时挂：表单 + 电话 + WhatsApp + Telegram + 邮件（全站置顶条 + 联系页），不要只留一个渠道。

## 八、后续迭代路线（建议顺序）

1. **扩型号**：目标 300+ 型号页，按 `docs/01_关键词覆盖表.md` 第五节的长尾模板扩词。
